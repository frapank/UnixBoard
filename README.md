# UnixBoard

**Terminal soundboard for your mic on Linux**

[![C++](https://img.shields.io/badge/C%2B%2B-17-00599C?style=flat-square&logo=cplusplus)](https://en.wikipedia.org/wiki/C%2B%2B17)
[![Status](https://img.shields.io/badge/status-early%20development-orange?style=flat-square)](#status)
[![License](https://img.shields.io/badge/license-GPL--3.0-blue?style=flat-square)](LICENSE)

</div>

A lightweight TUI for triggering sound clips straight into your microphone input on Linux. Pick a sound, click or hit a key, and it plays live :D

![screenshot](.github/assets/screenshot.png)

## Build

```sh
cmake -B build
cmake --build build -j
./build/unixboard
```
